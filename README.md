# Aurras Releases

This public repository hosts the Aurras Sparkle update feed and downloadable release artifacts.

## Download

Latest release:

```text
https://github.com/divineblu/aurras-releases/releases/latest
```

Direct DMG URL:

```text
https://github.com/divineblu/aurras-releases/releases/latest/download/Aurras.dmg
```

## Updates

Aurras checks this public Sparkle appcast:

```text
https://raw.githubusercontent.com/divineblu/aurras-releases/main/appcast.xml
```

The appcast entries are signed with Sparkle EdDSA. Release DMGs are signed with Developer ID and notarized by Apple.
